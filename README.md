# 2027학년도 중학교 교육과정 편성 자율 점검 시스템

학교가 제출한 `2027학년도 중학교 교육과정 편제표(.xlsm)`를 업로드하면, **1학년·2학년·3학년·학년전체** 시트를 각각 분석하여 `2027학년도 중학교 교육과정 편성 자율 점검표`의 준수 여부를 확인하는 Streamlit 기반 대시보드입니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 복수 파일 업로드 | 여러 학교의 `.xlsm` 편제표를 한 번에 업로드하고 일괄 파싱합니다. |
| 학교별 탭 | 업로드된 각 학교를 별도 탭으로 표시합니다. |
| 시트별 점검 | 각 학교의 `1학년`, `2학년`, `3학년`, `학년전체` 시트를 독립적으로 점검합니다. |
| 전체 자율 점검표 | 자율 점검표의 17개 기준을 모두 행으로 표시합니다. |
| 판정 매트릭스 | 각 기준별로 4개 시트의 결과를 `○`, `×`, `검토 필요`로 병렬 표시합니다. |
| 판정 근거 | 교과 시수, 허용 범위, 미준수 사유 및 추가 확인 필요 사항을 시트별로 제공합니다. |
| 학교별 총평 | 68개 판정값(17개 기준 × 4개 시트)의 준수·미준수·검토 필요 건수를 자동 요약합니다. |
| 통합 엑셀 | 모든 학교의 총평, 점검 결과, 판정 근거, 원시 편제 데이터를 하나의 엑셀 파일로 다운로드합니다. |
| 일괄 초기화 | 브라우저 세션에서 처리 중인 업로드 데이터와 점검 결과를 삭제합니다. |

## 화면과 판정 구조

각 학교 탭에서는 다음 형태의 점검표를 확인할 수 있습니다.

| 구분 | 점검 기준 | 1학년 | 2학년 | 3학년 | 학년전체 |
| --- | --- | --- | --- | --- | --- |
| 교과 시수 | 교과(군)별 증감 범위(3년간 기준시수의 20%)를 초과하지 않았는가? | ○ | ○ | ○ | ○ |
| 교과 시수 | 정보는 68시간 이상 편성하였는가? | ○ | ○ | ○ | ○ |
| 학교자율시간 | 학교자율시간 과목은 한 학기 33~34시간으로 편성하였는가? | ○ | ○ | ○ | ○ |
| 종합 | 범교과 학습 주제는 교육활동 전반에 통합 운영되도록 계획하였는가? | 검토 필요 | 검토 필요 | 검토 필요 | 검토 필요 |

| 판정 | 의미 | 필요한 조치 |
| --- | --- | --- |
| **○** | 편제표의 시수·과목·학기별 데이터로 기준 충족을 자동 확인 | 판정 근거를 확인한 뒤 유지합니다. |
| **×** | 지침상 시수 또는 편성 방식이 기준에 미달하거나 초과, 또는 필수 데이터가 없음 | 시수·과목명·운영 방식을 수정하고 재점검합니다. |
| **검토 필요** | 편제표만으로 확정할 수 없는 질적 기준 또는 미기재 정보 | 시간표, 수강신청, 평가계획, 연간 교육과정 운영계획을 함께 확인합니다. |

> `검토 필요`는 오류가 아니라 **추가 증빙 문서가 필요한 상태**입니다. 특히 실제 학생 선택권, 선택 과목의 성취도 산출 구분, 범교과 학습 주제의 통합 운영은 편제표만으로 최종 판단할 수 없습니다.

## 점검 기준

시스템은 다음 17개 자율 점검표 기준을 4개 시트에 대해 각각 점검합니다.

| ID | 구분 | 점검 기준 | 자동 점검 방식 |
| --- | --- | --- | --- |
| 01 | 교과 시수 | 교과(군)별 증감 범위 20% 준수 | 기준시수 대비 실제 운영시수가 80~120%인지 확인 |
| 02 | 교과 시수 | 체육·예술 기준 시수 준수 | 체육·예술이 각각 272시간 이상인지 확인 |
| 03 | 교과 시수 | 국어·수학·영어 통합 증감 102시간 이내 | 세 교과 증감 절대값의 합계 확인 |
| 04 | 교과 시수 | 정보 68시간 이상 편성 | 정보 교과와 정보 관련 학교자율시간 합산 |
| 05 | 선택 | 학생 선택권 실질 보장 | 선택 과목의 복수 편성과 종교 과목 단독 편성 여부 확인 |
| 06 | 선택 | 성취도 산출·미산출 과목 혼합 금지 | 선택군 코드와 알려진 과목 분류로 보조 점검 |
| 07 | 창·체 | 창의적 체험활동 20% 증감 범위 준수 | 학교스포츠클럽을 제외한 창체 245~367시간 확인 |
| 08 | 창·체 | 창체 세부 영역 균형 편성 | 자율·자치, 동아리, 진로 활동 편성 여부 확인 |
| 09 | 학교자율시간 | 3년 중 한 학기 이상 편성 | 운영 시수가 배정된 학기 존재 여부 확인 |
| 10 | 학교자율시간 | 한 학기 33~34시간 편성 | 운영 학기별 총 시수 확인 |
| 11 | 학교자율시간 | 학기 단위 이수 | 동일 과목이 1개 학기 내에 완결되는지 확인 |
| 12 | 자유학기 | 자유학기 활동 102시간 편성 | 자유학기 활동 시수 합계 확인 |
| 13 | 자유학기 | 자유학기 활동 2영역 편성 | 2개 이상 영역이 각각 17시간 이상인지 확인 |
| 14 | 종합 | 학기당 이수 과목 수 8개 이내 | 원본 시트의 제외 과목 반영 이수 과목 수를 사용 |
| 15 | 종합 | 체육 매 학기 편성 | 6개 학기 모두 체육 운영시수가 있는지 확인 |
| 16 | 종합 | 범교과 학습 주제 통합 운영 | 편제표 외 운영계획 확인이 필요하여 `검토 필요` 표시 |
| 17 | 종합 | 협력종합예술활동 17시간 이상 | 하단 표의 운영 시수 확인 |

## 설치 및 실행

### 사전 요구 사항

Python 3.10 이상을 권장합니다. 프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

실행 후 브라우저에서 표시되는 주소에 접속합니다. 기본적으로 `http://localhost:8501`에서 실행됩니다.

### 파일 업로드 및 점검 절차

1. 학교별 교육과정 편제표 `.xlsm` 파일을 하나 이상 선택합니다.

1. **업로드 파일 점검 시작** 버튼을 선택합니다.

1. 생성된 학교 탭에서 17개 기준과 4개 시트의 판정 결과를 확인합니다.

1. 점검표 아래의 **시트별 판정 근거**에서 계산값과 미준수 사유를 확인합니다.

1. 화면 하단의 **학교별 총평**을 확인합니다.

1. 필요 시 **전체 학교 점검 결과 엑셀 다운로드** 버튼을 선택합니다.

1. 새 작업을 시작하려면 **업로드·점검 결과 일괄 초기화** 버튼을 선택합니다.

> 학교는 **Excel에서 수식 계산을 완료한 뒤 저장한 파일**을 제출해야 합니다. 저장되지 않은 수식 결과 또는 이전 계산값이 남아 있는 파일은 부정확한 판정으로 이어질 수 있습니다.

## 엑셀 다운로드 구성

대시보드에서 생성하는 다운로드 파일에는 다음 시트가 포함됩니다.

| 다운로드 시트 | 내용 |
| --- | --- |
| `학교별 총평` | 학교 정보, 준수·미준수·검토 필요 건수, 자동 생성 총평 |
| `점검결과` | 17개 기준별 1학년·2학년·3학년·학년전체 판정 매트릭스 |
| `점검근거` | 시트별 결과, 계산값, 허용 범위, 수동 검토 사유 |
| `원시편제데이터` | 교과군, 과목명, 기준시수, 운영시수 및 학기별 운영시수 |

## GitHub 및 Streamlit Cloud 배포

개인정보 보호를 위해 원본 제출 파일과 실제 점검 결과 파일은 저장소에 커밋하지 않는 것을 권장합니다. 다음 예시는 소스 코드만 비공개 저장소에 올리는 절차입니다.

```bash
git init
git add app.py auditor.py utils.py requirements.txt README.md
git commit -m "feat: sheet-level curriculum audit dashboard"
git branch -M main
gh repo create middle-school-curriculum-audit --private --source=. --remote=origin --push
```

이후 [Streamlit Community Cloud](https://share.streamlit.io/)에서 GitHub 저장소를 연결하고, Main file path를 `app.py`로 지정해 배포합니다.
